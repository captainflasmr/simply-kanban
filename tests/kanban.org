*** DONE =.proto= files under =cuis-proto/src/main/proto/= defining:
**** DONE =UFCommonUIService= gRPC service (register, publish/subscribe object attributes, update/request attribute values, publish/subscribe interaction, send interaction)

Contracts first, nothing else in CUIS can compile without these generated classes, I think that defining a gradle build will just regenerate proto bindings without a separate script!! and be naturally part of the build process, when the other components are built through gradle they can just pull in this proto component and the java proto bindings will become naturally available.
