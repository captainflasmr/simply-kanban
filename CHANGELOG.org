* [Unreleased]

** Added

- Compact card layout (default): each card now condenses its metadata onto one line, listing the board and source-file markers when present, then effort, story points, clocked time, remaining or over-budget time, sprint, and tags, omitting values the card lacks.  Values are separated by spaces, numeric values drop their labels (~4:00 5 1h:30m 1h~), durations use colon-separated units (~1d:1h:23m~), and the sprint value appears without a ~Sprint:~ prefix.  The line truncates with an ellipsis when the column is narrow, while the title and progress bar keep their own lines.  Toggle the current board with ~c~ (~simply-kanban-toggle-compact~); ~simply-kanban-compact-cards~ (default ~t~) chooses the startup layout, and the detailed view still shows labelled badges.
- Card progress bars: each card with logged clocked time now shows its own bar of filled (~█~) and empty (~░~) blocks, using the same style as the column divider.  A ~DONE~ card is fully filled; any other card is filled by its clocked time against its ~Effort~ estimate, capped at fully complete.  Cards without an estimate, or with an estimate but no clocked time, show no bar unless they are ~DONE~, so untouched cards never display an empty bar.  Toggle with ~simply-kanban-show-card-progress~ (default ~t~).
- Title truncation: ~simply-kanban-max-title-length~ (default ~nil~) caps how many characters of a card's title the board shows, truncating longer titles with an ellipsis so the board stays compact.  Expanding a card with ~e~ restores its full title alongside the body, and ~l~ (~simply-kanban-set-title-length~) sets the limit live for the current board (empty input removes it) when the board feels too verbose.
- Jump from Org to the board: ~simply-kanban-show-card~ (bound to ~C-c ;~ in ~org-mode-map~), run from the source Org buffer, is the inverse of the board's ~RET~.  It finds the heading at -- or enclosing -- point among the board's cards and selects that card, showing the board in another window while focus stays in the Org buffer.  With a prefix argument (~C-u C-c ;~) or ~M-x simply-kanban-jump-to-card~, focus moves to the card on the board instead.  The matched card is filled with the new ~simply-kanban-mark~ face so you can see which card relates to the heading; the fill clears the moment you navigate to another card.  When no board is open it creates one for the file first (the whole-buffer board, or the all-boards aggregate for a multi-board file) in a split to the right, keeping the original file visible on the left, so the command always tries to take you to a card.  When point is on a non-card heading the nearest enclosing card is used.
- Sprints: a heading's ~SPRINT~ property (any text, read with inheritance) assigns it to a sprint.  ~S~ filters the board to one sprint (the header-line shows ~[sprint: TEXT]~), ~#~ sets/removes a card's ~SPRINT~, and ~simply-kanban-default-sprint~ (default ~nil~) chooses the sprint shown when a board opens.  While unfiltered each card shows a ~Sprint: TEXT~ badge (toggle with ~simply-kanban-show-sprint~, face ~simply-kanban-sprint~); the badge is hidden once filtered to a single sprint.  Set ~simply-kanban-sprint-from-heading~ non-nil to use the nearest ancestor heading without a TODO keyword as the sprint, letting a single file be split into sprints by its section headings; a nearer heading overrides a property on a higher ancestor, a property on the heading itself overrides its text, and a property on the card always wins.  Numeric-looking sprints sort numerically, other values lexically.  No date arithmetic is involved — membership is purely the sprint value.
- All-boards aggregate: in a multi-board file the chooser and ~B~ (~simply-kanban-switch-board~) now offer an "All Boards" entry that shows every board's cards in one view, with each card denoting its board (~▸ Project Alpha~).  Controlled by ~simply-kanban-all-boards~ (default ~t~) and named by ~simply-kanban-all-boards-name~.
- Effort estimates (Jira-style): a card shows its Org ~Effort~ property as an ~Effort: 2:00~ badge, and each column header sums its cards' efforts in brackets (~[2:00]~) for a per-stage workload total.  ~;~ sets the effort with Org's native ~org-set-effort~ prompt, then saves and refreshes.  Toggle the whole feature with ~simply-kanban-show-effort~ (default ~t~); the badge and total use the new ~simply-kanban-effort~ face.
- Story points: a card's ~STORY_POINTS~ property (a non-negative number, fractions allowed) is shown as a ~Points: 5~ badge and summed per column in parentheses (~(8 pts)~) after the card count.  ~P~ sets or removes the points, and ~simply-kanban-show-story-points~ (default ~t~) toggles the badges and totals.  The sprint summary gains a story-points column; the new ~simply-kanban-points~ face styles the badges.
- Sprint summary dynamic block: ~#+BEGIN: simply-kanban-sprint-summary :scope file~ writes a table of sprint, task count, done count, story points, effort-weighted progress, estimate, actual clocked time, and remaining estimate.  It uses the source buffer's ~org-duration-units~ and the Jira-style duration formatter, supports ~:scope subtree~, and updates with ~C-c C-c~ or ~org-update-all-dblocks~.
- Column progress bars: the divider under each column is now a bar of filled (~█~) and empty (~░~) blocks.  The filled share is completed estimated effort — ~DONE~ cards count fully and in-progress cards count clocked time capped at their estimate — falling back to the done-card count when no efforts are set.  The empty portion uses the ~shadow~ face and the filled portion uses the column's TODO-keyword colour.  Toggle with ~simply-kanban-show-column-progress~ (default ~t~).
- Clocking from the board: a card shows its Org clocked time as a ~Clocked: 1:30~ badge, with a running clock marked ~(run)~; the active clock is also shown in the header line.  ~i~ clocks in the card at point and ~o~ clocks out the running task.  ~simply-kanban-show-clock~ (default ~t~) controls the badges; ~simply-kanban-show-clock-total~ (default ~nil~) adds each column's clocked total in braces (~{1:30}~) after its effort total.  Started cards also show ~Remaining: 1d 3h 42m~ in Jira-style day/hour/minute units (the day length follows ~org-duration-units~ from the source buffer, so project dir-locals are respected), calculated as Effort minus clocked time, with ~simply-kanban-show-remaining~ (default ~t~) and an optional per-column remaining total via ~simply-kanban-show-remaining-total~ (default ~nil~, rendered as ~<1d 3h 42m>~).  The new ~simply-kanban-clock~ and ~simply-kanban-remaining~ faces style the badges.
- Running-card highlight: the card with the active Org clock is filled with the new ~simply-kanban-running-card~ face (inheriting ~highlight~), so the task in progress stands out from the currently focused card.  The highlight follows clock changes made from the board or elsewhere in Org, and clears on clock-out.
- Over-budget indicator: a card whose clocked time exceeds its estimate shows ~Over: 30m~ (face ~simply-kanban-over~, inheriting ~warning~) instead of ~Remaining: 0m~.  ~simply-kanban-show-over-total~ (default ~nil~) appends each column's summed over-budget time after an exclamation mark (~!30m~).
- Notes and logbook from the board: ~N~ adds a timestamped note to the card at point with Org's native note prompt, and boards refresh from ~org-after-note-stored-hook~ once the note is stored.  The board stays visible while the note is written: the source Org buffer and ~*Org Note*~ open in side windows, and an around-advice on ~org-store-log-note~ returns to the annotated card after storing or cancelling.  ~L~ toggles the card's ~LOGBOOK~ drawer on the board, showing clock entries and drawer notes below a ~Logbook~ divider.  ~e~ now strips ~LOGBOOK~ drawers and ~CLOCK~ lines from the expanded body, so it shows notes and prose without the clock log.

** Changed

- Multiple board buffers: each board now opens in its own buffer named from ~simply-kanban-buffer-name~ and its source (for example, ~*Simply Kanban: projects.org ▸ Project Alpha*~), so several boards can stay open at once.  Reopening a board reuses its buffer, ~B~ selects an already-open board, and ~simply-kanban-show-card~ uses the open board containing the heading or creates one.  The mode line now shows the descriptive buffer name instead of repeating the source.
- The active sprint filter and running clock now lead the board's header line, ahead of the follow indicator and key reminders, so a narrow window shows them first.
- The board's header line no longer shows the ~SPC menu~, ~s status~, or ~q quit~ hints; the transient menu is still available with ~SPC~ or ~?~, ~s~ still sets the card's status, and ~q~ still quits the board.
- The transient menu no longer has a Navigate group; use ~n~, ~p~, ~f~, and ~b~ directly on the board.

** Removed

- The ~v~ (~simply-kanban-jump-other-window~) binding has been removed: it revealed the heading but left focus on the board, making it behave like ~RET~.  ~RET~ still reveals the heading in another window without leaving the board.

* [0.4.0] - 2026-05-31

** Added

- Multiple boards per file: a level-1 heading with no TODO keyword becomes a separate board whose cards are the TODO headings in its subtree.  When a file defines several, ~simply-kanban~ prompts for which to open and ~B~ (~simply-kanban-switch-board~) switches between them.
- Top-level board: loose level-1 TODO headings in a multi-board file are still offered as a flat board, named by ~simply-kanban-toplevel-name~ (default "Top Level").
- Card body expansion: ~e~ toggles the Org body of the card at point in and out, ~E~ toggles every card.  Plain flat files are unaffected.
- Tags on cards: a card now shows its Org tags below the title, in ~:tag:~ form using the new ~simply-kanban-tag~ face.
- Set tags from the board: ~:~ runs Org's native tag prompt on the card's heading, then saves and refreshes.
- Set priority from the board: ~,~ runs Org's native priority prompt on the card's heading, then saves and refreshes.
- Heading pulse: revealing a heading (~RET~) and follow mode briefly pulse the target Org heading line.  Toggle with ~simply-kanban-pulse-on-goto~ (default ~t~); the pulse uses the new ~simply-kanban-flash~ face.
- Save after change: ~simply-kanban-save-after-change~ (default ~t~) saves the source Org buffer after a status change or deletion.
- Transient menu: press ~SPC~ on the board for a ~transient~ menu grouping every command (Navigate / Move-Edit / Reveal / Board), modelled on the menu in simply-annotate.  Adds a ~transient~ (0.4) dependency (bundled with Emacs 28.1+).

** Changed

- Compact cards: cards now fit far more per window.  A card shows its title (prefixed by an Org priority cookie such as ~[#A]~ only when one is set), its tags when present, and -- in an aggregated board -- its source file (~» file~).  The always-on priority/location/author lines, the metadata divider, and the blank line between cards were removed.
- ~RET~ no longer moves focus to the Org file: it reveals the heading in another window while keeping point on the board.
- Column headers now render the keyword title above the divider rule (previously inverted).
- Card titles render in the normal weight and only become bold when the card is focused; the focused-card highlight uses a bold weight rather than a background color.

** Removed

- Automatic column refit on window resize (the ~window-size-change-functions~ hook): it added noticeable lag.  Press ~g~ to refit after resizing.

** Fixed

- Heading body extraction no longer captures the following heading's text when an entry has no content of its own.

* [0.3.0] - 2026-05-31

** Added

- Color-coded TODO states: column headers and card borders now use the same colors as Org mode's TODO keywords. Respects custom faces defined in ~org-todo-keyword-faces~, falling back to ~org-todo~ for active states and ~org-done~ for done states.

* [0.2.0] - 2026-05-31

** Added

- Tag filtering: press ~t~ to filter the board by tag, ~T~ to clear the filter.  Active filter is shown in the header line.
- Delete card: press ~k~ to delete the Org heading at point (with confirmation).
- Jump to source in another window: press ~v~ to open the heading in a split window, keeping the board visible.
- Priority sorting: new customisation option ~simply-kanban-sort-by-priority~ (default ~nil~). When enabled, cards within each column are sorted by priority (A > B > C > none).
- Automatic column refit on window resize via ~window-size-change-functions~.

** Changed

- Column width calculation now uses ~window-width~ (matching simply-annotate) with robust fallback handling for edge cases.
- Header line updated to show new keybindings: ~v~ (view), ~k~ (delete), ~t/T~ (tag filter).

** Fixed

- Column sizing on ~g~ (refresh) now correctly recalculates to fit the current window width.

* [0.1.0] - 2026-05-31

** Added

- Initial release: lightweight kanban board for Org files.
- Columns are the buffer's Org TODO keywords (the ~#+TODO:~ workflow).
- Cards are the headings carrying those keywords.
- Moving a card between columns changes the heading's TODO state via ~org-todo~, written straight back to the Org buffer (no separate database).
- Navigation: ~n~/~p~ (cards), ~f~/~b~/~TAB~/~S-TAB~ (columns), wrapping.
- Actions: ~}~/~{~ (advance/retreat stage), ~s~ (set status), ~RET~ (jump to heading).
- Follow mode: press ~F~ to show the heading as you navigate.
- Auto-refresh on source buffer save.
- Multi-file aggregation via ~M-x simply-kanban-agenda~ (uses ~org-agenda-files~).
- Each card in an aggregated board shows its source file and follows that file's own workflow.
- ERT test suite with ~make test~, ~make compile~, ~make checkdoc~, ~make lint~.
- GitHub Actions CI across Emacs 27.2–30.1 and snapshot.
