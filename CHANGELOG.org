* [Unreleased]

** Added

- All-boards aggregate: in a multi-board file the chooser and ~B~ (~simply-kanban-switch-board~) now offer an "All Boards" entry that shows every board's cards in one view, with each card denoting its board (~▸ Project Alpha~).  Controlled by ~simply-kanban-all-boards~ (default ~t~) and named by ~simply-kanban-all-boards-name~.
- Effort estimates (Jira-style): a card shows its Org ~Effort~ property as an ~Effort: 2:00~ badge, and each column header sums its cards' efforts in brackets (~[2:00]~) for a per-stage workload total.  ~;~ sets the effort with Org's native ~org-set-effort~ prompt, then saves and refreshes.  Toggle the whole feature with ~simply-kanban-show-effort~ (default ~t~); the badge and total use the new ~simply-kanban-effort~ face.

* [0.4.0] - 2026-05-31

** Added

- Multiple boards per file: a level-1 heading with no TODO keyword becomes a separate board whose cards are the TODO headings in its subtree.  When a file defines several, ~simply-kanban~ prompts for which to open and ~B~ (~simply-kanban-switch-board~) switches between them.
- Top-level board: loose level-1 TODO headings in a multi-board file are still offered as a flat board, named by ~simply-kanban-toplevel-name~ (default "Top Level").
- Card body expansion: ~e~ toggles the Org body of the card at point in and out, ~E~ toggles every card.  Plain flat files are unaffected.
- Tags on cards: a card now shows its Org tags below the title, in ~:tag:~ form using the new ~simply-kanban-tag~ face.
- Set tags from the board: ~:~ runs Org's native tag prompt on the card's heading, then saves and refreshes.
- Set priority from the board: ~,~ runs Org's native priority prompt on the card's heading, then saves and refreshes.
- Heading pulse: revealing a heading (~RET~) and follow mode briefly pulse the target Org heading line.  Toggle with ~simply-kanban-pulse-on-goto~ (default ~t~); the pulse uses the new ~simply-kanban-flash~ face.
- Save after change: ~simply-kanban-save-after-change~ (default ~t~) saves the source Org buffer after a status change or deletion.
- Transient menu: press ~SPC~ on the board for a ~transient~ menu grouping every command (Navigate / Move-Edit / Reveal / Board), modelled on the menu in simply-annotate.  Adds a ~transient~ (0.4) dependency (bundled with Emacs 28.1+).

** Changed

- Compact cards: cards now fit far more per window.  A card shows its title (prefixed by an Org priority cookie such as ~[#A]~ only when one is set), its tags when present, and -- in an aggregated board -- its source file (~» file~).  The always-on priority/location/author lines, the metadata divider, and the blank line between cards were removed.
- ~RET~ no longer moves focus to the Org file: it reveals the heading in another window while keeping point on the board.
- Column headers now render the keyword title above the divider rule (previously inverted).
- Card titles render in the normal weight and only become bold when the card is focused; the focused-card highlight uses a bold weight rather than a background color.

** Removed

- Automatic column refit on window resize (the ~window-size-change-functions~ hook): it added noticeable lag.  Press ~g~ to refit after resizing.

** Fixed

- Heading body extraction no longer captures the following heading's text when an entry has no content of its own.

* [0.3.0] - 2026-05-31

** Added

- Color-coded TODO states: column headers and card borders now use the same colors as Org mode's TODO keywords. Respects custom faces defined in ~org-todo-keyword-faces~, falling back to ~org-todo~ for active states and ~org-done~ for done states.

* [0.2.0] - 2026-05-31

** Added

- Tag filtering: press ~t~ to filter the board by tag, ~T~ to clear the filter.  Active filter is shown in the header line.
- Delete card: press ~k~ to delete the Org heading at point (with confirmation).
- Jump to source in another window: press ~v~ to open the heading in a split window, keeping the board visible.
- Priority sorting: new customisation option ~simply-kanban-sort-by-priority~ (default ~nil~). When enabled, cards within each column are sorted by priority (A > B > C > none).
- Automatic column refit on window resize via ~window-size-change-functions~.

** Changed

- Column width calculation now uses ~window-width~ (matching simply-annotate) with robust fallback handling for edge cases.
- Header line updated to show new keybindings: ~v~ (view), ~k~ (delete), ~t/T~ (tag filter).

** Fixed

- Column sizing on ~g~ (refresh) now correctly recalculates to fit the current window width.

* [0.1.0] - 2026-05-31

** Added

- Initial release: lightweight kanban board for Org files.
- Columns are the buffer's Org TODO keywords (the ~#+TODO:~ workflow).
- Cards are the headings carrying those keywords.
- Moving a card between columns changes the heading's TODO state via ~org-todo~, written straight back to the Org buffer (no separate database).
- Navigation: ~n~/~p~ (cards), ~f~/~b~/~TAB~/~S-TAB~ (columns), wrapping.
- Actions: ~}~/~{~ (advance/retreat stage), ~s~ (set status), ~RET~ (jump to heading).
- Follow mode: press ~F~ to show the heading as you navigate.
- Auto-refresh on source buffer save.
- Multi-file aggregation via ~M-x simply-kanban-agenda~ (uses ~org-agenda-files~).
- Each card in an aggregated board shows its source file and follows that file's own workflow.
- ERT test suite with ~make test~, ~make compile~, ~make checkdoc~, ~make lint~.
- GitHub Actions CI across Emacs 27.2–30.1 and snapshot.
