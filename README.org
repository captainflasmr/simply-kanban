A lightweight kanban board for Org files.  The board is a live view of the
current Org buffer — there is *no separate database*, the Org file is the
single source of truth.

- *Columns* are the buffer's Org TODO keywords (the =#+TODO:= workflow, e.g.
  =TODO NEXT DOING | DONE=).
- *Cards* are the headings carrying those keywords.
- *Moving a card* between columns changes the heading's TODO state via
  =org-todo=, written straight back to the Org buffer.

The rendering and navigation are modelled on the kanban view in
[[https://github.com/captainflasmr/simply-annotate][simply-annotate]].

* Status

Early MVP (v0.1.0).  Works against the current Org buffer or all agenda files.
Strictly keyboard-driven.  Future ideas: WIP limits, priority/tag filtering,
scheduled/deadline badges, swimlanes by tag.

* Install

Clone and load:

#+begin_src elisp
(add-to-list 'load-path "/path/to/simply-kanban")
(require 'simply-kanban)
#+end_src

* Usage

Open an Org file with TODO headings and run =M-x simply-kanban= for a board of
the current buffer, or =M-x simply-kanban-agenda= for a board aggregating all
your =org-agenda-files=.

In an aggregated board the columns are the *union* of the agenda files' TODO
keywords, and each card shows which file it comes from (=» file.org=).  Moving a
card follows that card's *own* file workflow and is written back to that file,
so files using different keyword sequences coexist safely.

| Key                | Action                              |
|--------------------+-------------------------------------|
| =n= / =p=          | next / previous card                |
| =TAB= / =S-TAB=    | next / previous column (also =f=/=b=) |
| =}= / =S-right=    | advance card to the next stage      |
| ={= / =S-left=     | send card back a stage              |
| =RET=              | jump to the heading in the Org file |
| =g=                | refresh                             |
| =q=                | quit                                |

* Customisation

- =simply-kanban-column-width= (default 30) — width of each column.
- =simply-kanban-column-gap= (default 2) — spaces between columns.
- =simply-kanban-buffer-name= — name of the board buffer.
- =simply-kanban-auto-refresh= (default =t=) — refresh the board automatically
  whenever its source Org buffer is saved.

* Development

There is an ERT suite and a =Makefile=:

#+begin_src bash
make test       # run the ERT suite
make compile    # byte-compile, treating warnings as errors
make checkdoc   # run checkdoc
make lint       # run package-lint (after `make deps')
make deps       # install package-lint into ./.elpa
make all        # compile + test + checkdoc
#+end_src

A GitHub Actions workflow (=.github/workflows/ci.yml=) runs these across Emacs
27.2–30.1 and snapshot on every push and pull request.
