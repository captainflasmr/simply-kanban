A lightweight kanban board for Org files.  The board is a live view of the current Org buffer — there is *no separate database*, the Org file is the single source of truth.

- *Columns* are the buffer's Org TODO keywords (the =#+TODO:= workflow, e.g.  =TODO NEXT DOING | DONE=).
- *Cards* are the headings carrying those keywords.
- *Moving a card* between columns changes the heading's TODO state via =org-todo=, written straight back to the Org buffer.

The rendering and navigation are modelled on the kanban view in [[https://github.com/captainflasmr/simply-annotate][simply-annotate]].

* Status

Works against the current Org buffer, a multi-board Org file, or all agenda files.  Strictly keyboard-driven.  Future ideas: WIP limits, scheduled/deadline badges, swimlanes by tag.

* Install

Clone and load:

#+begin_src elisp
(add-to-list 'load-path "/path/to/simply-kanban")
(require 'simply-kanban)
#+end_src

* Usage

Open an Org file with TODO headings and run =M-x simply-kanban= for a board of the current buffer, or =M-x simply-kanban-agenda= for a board aggregating all your =org-agenda-files=.

In an aggregated board the columns are the *union* of the agenda files' TODO keywords, and each card shows which file it comes from (=» file.org=).  Moving a card follows that card's *own* file workflow and is written back to that file, so files using different keyword sequences coexist safely.

A header-line shows the source and the key reminders.  Columns expand to fill the board window; after resizing the window press =g= to refit them.

| Key       | Action                                               |
|-----------+------------------------------------------------------|
| =n= / =p= | move down / up the cards in a column                 |
| =f= / =b= | move across columns (also =TAB= / =S-TAB=), wrapping |
| =}= / ={= | advance / retreat card a stage                       |
| =s=       | set status (choose any stage)                        |
| =RET=     | reveal the heading (focus stays on the board)        |
| =v=       | jump to the heading in another window                |
| =k=       | delete the heading (with confirmation)               |
| =t=       | filter board by tag                                  |
| =T=       | clear tag filter                                     |
| =:=       | set the Org tags on the card at point                |
| =,=       | set the Org priority of the card at point            |
| =e= / =E= | toggle the body of the card / every card             |
| =F=       | toggle follow mode (show heading as you move)        |
| =B=       | switch board (multi-board files only)                |
| =g=       | refresh                                              |
| =q=       | quit                                                 |

The card at point is highlighted, and navigating moves the highlight onto the new card.

Cards are deliberately compact so you can fit many per window: a card shows its title (prefixed by a priority cookie such as =[#A]= only when one is set) and, when present, its tags.  In an aggregated board it also shows its source file (=» file=).  Press =e= to expand a card and show the heading's body text inline.  When you reveal a heading with =RET= (or while follow mode is on) the target heading line briefly pulses, and focus stays on the board.

* Multiple boards in one file

A single Org file can hold several boards.  Make each board a *level-1 heading with no TODO keyword* and put its cards as TODO headings inside that subtree:

#+begin_src org
,* Project Alpha
,** TODO design
,** DOING build
,* Project Beta
,** TODO research
,** DONE prototype
#+end_src

=M-x simply-kanban= then prompts for which board to open, and =B= switches between them.  Any *loose* level-1 TODO headings sitting at the top of the file (outside a board heading) are still offered as a flat board named by =simply-kanban-toplevel-name= ("Top Level" by default).  A plain file whose top-level headings are themselves TODO items continues to open as a single flat board, exactly as before.

Status changes and deletions are written straight back to the source file and, by default, saved (see =simply-kanban-save-after-change=).

* Customisation

- =simply-kanban-min-column-width= (default 24) — columns expand to fill the window but never go narrower than this.
- =simply-kanban-column-gap= (default 2) — spaces between columns.
- =simply-kanban-buffer-name= — name of the board buffer.
- =simply-kanban-auto-refresh= (default =t=) — refresh the board automatically whenever its source Org buffer is saved.
- =simply-kanban-sort-by-priority= (default =nil=) — when non-nil, sort cards within each column by priority (A > B > C > none).
- =simply-kanban-save-after-change= (default =t=) — save the source Org buffer after a status change or deletion.
- =simply-kanban-pulse-on-goto= (default =t=) — briefly pulse the target heading line when revealing it (=RET= and follow mode).
- =simply-kanban-toplevel-name= (default ="Top Level"=) — name of the flat board holding a multi-board file's loose level-1 TODO headings.

Faces: =simply-kanban-header-line= (the top header-line bar), =simply-kanban-current-card= (focused card), =simply-kanban-tag= (card tags), =simply-kanban-flash= (heading pulse), =simply-kanban-column-header=.

* Development

There is an ERT suite and a =Makefile=:

#+begin_src bash
make test       # run the ERT suite
make compile    # byte-compile, treating warnings as errors
make checkdoc   # run checkdoc
make lint       # run package-lint (after `make deps')
make deps       # install package-lint into ./.elpa
make all        # compile + test + checkdoc
#+end_src

A GitHub Actions workflow (=.github/workflows/ci.yml=) runs these across Emacs 27.2–30.1 and snapshot on every push and pull request.
